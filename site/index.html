Why it won't cry wolf

A false alarm on a private repo is the one thing that gets a tool uninstalled. So caution is built in, not hoped for:

  • A model named in a README or comment is never a build-failing error — only real config is.
  • A variable named o1 is never mistaken for the o1 model. Only quoted pins count.
  • Every finding links an official source + date — verify any claim in seconds.
  • The catalog is built by fetching live docs, never memory — the exact bug this tool exists to catch.
  • This first version structurally cannot fail your build with a false positive — worst case is a warning.
